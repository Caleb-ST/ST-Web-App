How duty cycle works

Duty cycle is the percentage of a standard test period that a welder can operate at a stated output before thermal limits require cooling. A rating of 200 A @ 30% means the machine is rated for about 3 minutes of welding and 7 minutes of cooling within the reference 10-minute cycle at those test conditions.

For a rough comparison at a different current, this tool uses the common thermal approximation D₂ = D₁ × (I₁ ÷ I₂)², capped at 100%. Real performance can differ with ambient temperature, process, input supply, torch rating, fan behaviour and the manufacturer’s test standard. Use published machine data whenever it is available.
